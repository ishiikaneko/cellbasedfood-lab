# メルマガ配信の法令対応メモ

培養肉・細胞農業ブログのメルマガ配信で守るべき日本の法令と、実運用でのチェックリスト。
（本メモは弁護士監修ではありません。判断に迷う場合は専門家に確認してください。）

対象法令：**特定電子メール法**（広告宣伝メールの規制）／**個人情報保護法**／宣伝時は**特定商取引法**。

---

## 1. すべてのメルマガに必ず入れるフッター

広告・宣伝を含むメールには、本文中に **送信者名・住所・配信停止方法** の表示が義務。

### コードから送るメール（確認メール等）

`src/lib/email/legal-footer.ts` の `legalFooterHtml()` / `legalFooterText()` を
**本文末尾に必ず入れる**。送信者情報を変えるときはこのファイルだけ直せば全メールに反映される。

### Resend ダッシュボード（Broadcasts）から送る月次メルマガ

こちらはコードを経由しないので footer が自動で入らない。**下記をコピペして毎回貼る**。
配信停止リンクは Resend の変数 `{{{RESEND_UNSUBSCRIBE_URL}}}` を使う。

**HTML 用：**

```html
<hr style="margin:36px 0;border:none;border-top:0.5px solid #e5e4df">
<p style="font-size:12px;color:#888;line-height:1.9;margin:0">
  <strong style="color:#666">細胞培養食品ラボ｜CellBasedFood Lab</strong><br>
  〒103-0027 東京都中央区日本橋2丁目16-4 remix日本橋 6階<br>
  お問い合わせ：<a href="https://cellbasedfood-lab.com/contact">https://cellbasedfood-lab.com/contact</a><br>
```

## 2. 登録・同意まわり（実装済み）

- **オプトイン**：登録フォームで同意チェック必須（`consent === true` を API で強制）。
- **同意文言**：「プライバシーポリシーに同意し、メールマガジンの配信を受け取る」を明示。
- **同意の記録**：登録時に日時・IP・UA・同意文言を構造化ログで保存（`subscribe.ts`）。
  ※ Vercel のログは保持期間に上限あり。長期・確実に残すなら DB 等への保存に切り替える。
- **オプトアウト**：HMAC トークン付き配信停止リンク＋動作する配信停止 API。

## 3. 今後、宣伝（有料商品・書籍・サービス等）をメルマガで送る場合

無料の情報配信に留まる限りは追加対応は基本不要だが、**有料商品の販売・勧誘**を行うなら以下を追加で守る。

### 3-1. 特定電子メール法（宣伝メール全般）

- 上記フッター（送信者名・住所・配信停止）は宣伝メールでも当然必須。
- **同意の範囲**を確認：登録時に得た同意が「宣伝も受け取る」ことを含むか。
  現状の同意文言（メルマガ配信の受信）は広告を含む運用として説明可能だが、
  性質が大きく変わる宣伝を始めるなら、登録ページ・プライバシーポリシーの記載を
  「新着記事・**関連商品/書籍等の案内**を配信」と具体化しておくと安全。

### 3-2. 特定商取引法（有料商品を販売・勧誘する場合）

メルマガから商品購入・申込みに誘導するなら、**特定商取引法に基づく表記**ページが必要。
最低限、以下を記載したページ（例：`/legal` や `/tokushoho`）を用意し、メルマガからリンクする。

- 販売事業者名（氏名／名称）・所在地・連絡先
- 販売価格・送料等の追加費用
- 代金の支払時期・方法
- 商品の引渡し時期
- 返品・キャンセルの条件（返品特約）

※ 自分の商品ではなくアフィリエイト（Amazon 等の紹介リンク）を貼るだけなら、
特商法の表記義務は基本かからないが、**広告であることを明示**（「※本メールにはアフィリエイトリンクを含みます」等）するのが望ましい。景品表示法（優良誤認・有利誤認）にも注意。

### 3-3. 始める前のチェックリスト

- [ ] 宣伝メールにもフッター（送信者名・住所・配信停止）が入っているか
- [ ] 有料商品を売るなら「特定商取引法に基づく表記」ページを用意しリンクしたか
- [ ] アフィリエイトなら広告である旨を明示したか
- [ ] 誇大・断定的な表現になっていないか（景品表示法・薬機法※健康効果を謳う場合）
- [ ] 登録時の同意範囲と実際の配信内容がずれていないか
